
# SMART CAMPUS ACADEMIC SERVICES PLATFORM (SCASP)

## 1. Problem Definition

### 1.1 Background

Higher education institutions handle various academic services, including course registration, student enquiries, academic requests, announcements and administrative reporting. When these activities are managed through disconnected systems or manual processes, students and staff may experience delays, difficulties accessing information and challenges tracking academic activities.

The Smart Campus Academic Services Platform (SCASP) is proposed as an integrated software solution designed to improve the delivery and management of academic services within a higher education institution.

### 1.2 Problem Statement

The institution requires a centralised platform that enables students to access academic services efficiently while allowing administrative staff to manage academic activities effectively. The absence of an integrated system can make course registration, waiting-list management, academic request processing and communication difficult to coordinate.

SCASP aims to address these challenges by providing a unified platform that supports academic service delivery through desktop, web and mobile technologies.

### 1.3 Proposed Solution

The proposed Smart Campus Academic Services Platform will provide a centralised system through which students can:

- View available courses and course information.
- Submit course registration and withdrawal requests.
- Join course waiting lists when capacity is reached.
- Submit and track academic service requests.
- View institutional announcements.
- Receive notifications about important academic activities.
- Locate selected campus services.

Administrative staff will be able to manage courses, process student requests, monitor registration capacity, publish announcements and generate reports.

### 1.4 Intended Users

The platform will serve the following users:

1. **Students:** Access academic services, register for courses, submit requests and receive announcements.
2. **Administrative Staff:** Manage courses, process requests, monitor student registrations and generate reports.
3. **System Administrators:** Manage user accounts, system access and overall platform operations.

### 1.5 Project Objective

The main objective of SCASP is to design, develop and test an integrated Java-based academic services platform that improves accessibility, efficiency, communication and management of academic services within a higher education institution.

The system will progressively incorporate Java Collections, multithreading, networking, enterprise services, JDBC, web technologies, remote method invocation and Android application development.
