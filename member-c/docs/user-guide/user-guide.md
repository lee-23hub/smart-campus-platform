## Students
1. **Log in** at the login page. Your name and role appear at the top.
2. **Find a course**: open *Courses*, type part of a code or title, choose a sort, press *Apply*.
3. **Register**: press *Register*. If the course is full the button says *Join waiting list*; you get a position number.
4. **See your registrations**: open *Registrations*. Status is REGISTERED or WAITLISTED.
5. **Withdraw**: press *Withdraw*. If you were registered, the next waiting student is promoted automatically.
6. **Raise a request**: open *Requests*, pick a category (transcript, clearance, appeal), a priority, write a short description (up to 500 characters) and press *Submit request*.
7. **Log out** with the button at top right.

## Staff
1. Log in with a staff account; a *Reports* link appears.
2. **Courses**: use *Add or update a course* (code like BOCS3100, title, capacity 1-500).
3. **Requests**: the list is ordered by priority; assigned staff are shown.
4. **Reports**: capacity, request workload and the audit trail.

## If something goes wrong
| You see | Meaning | Do this |
|---------|---------|---------|
| Red message under a field | Input not accepted | Fix that field and submit again |
| Back at login page | Session ended | Log in again |
| "No ... to show" | Nothing matches yet | Change search or come back later |
