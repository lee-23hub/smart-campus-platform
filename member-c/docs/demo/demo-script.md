# Final Demonstration Script (30 minutes)
All three members speak. Practise twice with a timer. Each member prepares one design decision and one code segment to explain.

| Time | Section | Show | Speaker (suggested) |
|------|---------|------|---------------------|
| 0:00-2:00 | Problem, architecture, roles | Architecture diagram, role rotation history | A |
| 2:00-6:00 | Collections, domain rules, persistence | Fill a course, waiting list, withdraw, promotion; JDBC transaction commit and rollback | B |
| 6:00-10:00 | Concurrency, networking, failures | 1,000 parallel registrations, race-condition evidence, TCP client, malformed message, timeout | B |
| 10:00-14:00 | Enterprise and web workflow, roles | Login, role check, direct unauthorised URL, register, request | C |
| 14:00-17:00 | RMI and CORBA | Remote admin client, server down message, IDL and migration slide | A |
| 17:00-20:00 | Android | Login, list, rotate, airplane mode, map, permission denied | C |
| 20:00-25:00 | Questions, viva, requested change | Be ready to edit a validator and re-run tests | All |

## Safety net
- Backup screen recording of every section.
- Pre-loaded sample data; reset script ready.
- Printed README and the test report.
